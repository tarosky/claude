# GUI 手順ナビ（clasp が使えないときの逃げ道）

Node が入れられない、`clasp login` が管理者に止められている、などで clasp モードが使えないときの進め方。
人間がブラウザで操作し、Claude は「どこを押して、何を貼るか」を1ステップずつ指示する。

**Claude 側の作業**：コードはローカルの `src/*.js` に書き、本人にはファイルごとに中身を貼ってもらう。ローカルにも同じものが残るので、後から clasp モードに移行できる（`clasp clone-script <スクリプトID>` で取り込める）。

## 1) 置き場所を決めてシートを作る

`usage-patterns.md` で決めた置き場所（マイドライブ or 共有ドライブ）で：

- **シートを使う**（結果をシートに書く場合は、きっかけが Gmail や時間でもこちら）：Google ドライブ →「新規」→ Google スプレッドシート
- **シートを使わない**：Google ドライブ →「新規」→ その他 → Google Apps Script
- **シートやフォームがすでにある**：それを使う。フォームの場合は、フォームの「回答」タブ →「スプレッドシートにリンク」で回答先シートを作り、**そのシート**で手順2へ

列の構成は Claude が要件から提案し、1行目の見出しを本人に入力してもらう。

## 2) Apps Script を開く

- シート起点：シート上部メニュー **拡張機能 → Apps Script**
- 独立スクリプト：手順1で作ったものを開く

左上の「無題のプロジェクト」をクリックして名前を付けてもらう。

## 3) コードを貼る

1. 最初からある `コード.gs` の中身を全部消し、Claude の `src/main.js` を貼る
2. ファイルが複数ある場合：左の「ファイル」の **＋ → スクリプト** で追加し、`setup` などの名前を付けて貼る
3. **💾 保存**（Ctrl+S / ⌘+S）

`appsscript.json`（タイムゾーンなど）を変える必要があるときだけ：⚙ プロジェクトの設定 →「appsscript.json マニフェスト ファイルをエディタで表示する」にチェック。通常は「タイムゾーン」を東京にするだけでよい。

## 4) 動かして承認する

`clasp-workflow.md` の「6) 動かして確かめる」と同じ（関数を選んで実行 → 承認 → 実行ログを確認）。

## 5) トリガーを張る

`setup()` を選んで1回実行（`triggers.md`）。GUI のトリガー画面（左の⏰）で張ってもよいが、張り直しのときに手順を再現しにくいので、`setup()` を推奨する。

## 6) Web画面にする場合

右上 **デプロイ → 新しいデプロイ** →「種類の選択」の⚙で **ウェブアプリ**：

- 次のユーザーとして実行：**自分**
- アクセスできるユーザー：**（会社名）内の全員**
- デプロイ → 表示されたURLが社内向けの画面

更新したら **デプロイ → デプロイを管理 → ✏ 編集 → バージョン「新バージョン」→ デプロイ**。URLは変わらない。

## 7) ライブラリ化は GUI では行わない

利用形態②でライブラリ化を選んだ場合は、clasp モードで作る（プロジェクトが2つになり、版の管理が要るため）。GUI 手順ナビの場合は、②は「割り切り（コピーで配る）」で作る。

## 引き継ぎのための一言

コードがシートの中に隠れて、後から誰も存在に気づかなくなりがち。シートに**「説明」タブ**を作り、README（Claude が書いたもの）の中身を貼ってもらう。ドライブに `.md` ファイルを置いても、ほとんど読まれない。

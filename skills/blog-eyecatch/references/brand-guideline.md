# Maintic ブランドガイドライン（2026-09-15 実サイトで確認）

このスキルの作成時点では配色・フォントが未確認で、濃紺(`#0B1E3D`)＋水色(`#3AA0FF`)＋白抜き文字という
**憶測のプレースホルダー**が置かれていた。2026-09-15に実サイトを確認したところ、実際のブランドは
まったく別物（温白色の地に黒見出し＋臙脂サブ＋黒線のフラットイラスト）だったため、
このファイルと`template/eyecatch.html`を実測値で置き換えた。

一次資料（Figma／ブランドブック）はまだ確認できていない。以下は実サイトのCSSプリセットと
現行og:imageのピクセル実測から取ったもので、**実装上はこれで十分一致する**が、
公式資料が出てきたら突き合わせること。

## フォント

- 和文・欧文とも **Noto Sans JP**（`--wp--preset--font-family--noto-sans-jp`）。サイト本体と同じ。
- 見出しは weight 900、サブタイトルは 700。
- `font-feature-settings: "palt" 1;` で字間を詰める（社内Slackでの提案）。
- `word-break: auto-phrase;` を併用し、「作/り方」のような語中での折り返しを防ぐ
  （Chromium 119+ が必要。Playwrightの同梱Chromiumなら問題ない）。

### layout-guide-logo.png の実測値（1200×630 = og:imageサイズ）

| 要素 | 位置・サイズ | master(1600×900)換算 |
|---|---|---|
| ロゴ | 200×40 @ (64, 58) | 266.67×53.3 @ (85.33, 107.33) |
| Mマークの円 | 中心(1063.5, 493.5)・半径343.5（外接矩形 687px @ (720,150)。右下へ207pxずつはみ出す） | 幅916px @ (960, 230) |
| 地色 | `#FCF9F4` | 同じ |

master換算は `x_master = x_og / 0.75`、`y_master = y_og / 0.75 + 30`（og:imageがmasterを
y=30起点で1600×840にクロップ→0.75倍する手順の逆算。`references/rendering.md`参照）。
**ガイドには装飾（ドット・細線など）は一切無い。** 初版で足していた自作の装飾は削除済み。勝手に足さない。

**ロゴは文字を組み直して似せないこと。** このスキルの初版は`●MAINTIC｜WP Platform`をテキストで再現していたが、
実際のロックアップは2段組みで字形も違う、別物だった。支給SVGをそのまま埋め込む。

**bg.svgの位置は上表のとおり。** 右下へはみ出させて、Mの左上側が見える状態にする。
イラストの真後ろに小さく敷くとMが完全に隠れてただの円になり、支給アセットを使う意味が無くなる。
色はファイル側の値をそのまま使い、塗り替えない。

## イラストの画風（デザイナー指定）

- **フラット＋アイソメトリック**。グラデーション・影は使わず平面的に
- 輪郭線は `#242424` の太線（`stroke-width: 6` 相当）
- 差し色 `#A60C30` / `#C2042D`、補助色 `#DDDDDD` / 白 / `#F7ECE9`
- モチーフは2〜4個、大小のリズムをつける
- 視点は**方位角32°・仰角45°**（左斜め上から見下ろす構図）。正等角投影の45°だと正面から見た左右対称になる

アイソメトリックは `scripts/iso.py` で描く（`references/design-process.md` の手順3.5）。
**「アイソメトリックは画像生成AIでないと描けない」わけではない。** 等角投影は座標変換なので、
SVGの方が線幅・配色が正確に揃う。

## レイアウトの型（現行og:imageから踏襲）

現行のアイキャッチは「タイトルを`｜`で割り、前半を黒の主題・後半を臙脂のサブにする」構成になっている。
`template/eyecatch.html`はこれを再現していて、`scripts/render.mjs`が`｜`で自動分割する。

- 地色 `#FCF9F4` の上に、右下へ`bg.svg`のMマーク（淡いピンク）
- 左カラム（幅900px）に `logo.svg` → 黒の主題 → 臙脂のサブ
- 右カラムにフラットイラストのモチーフ（黒アウトライン6px・白面・赤アクセント）
